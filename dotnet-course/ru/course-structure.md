# Курс по .NET — структура

Спецкурс для 4-го курса БГУИР. **15 лекций × 80 минут**, лабораторные коррелируют с лекциями.

**Сквозная цель:** на выходе студент собирает WebAPI-сервис из частей, понимая каждую часть.

**Принципы построения:**

- внутри каждой темы движение от общего к деталям — каждая подтема сложнее предыдущей;
- .NET internals — только мельком, с целью направить на самостоятельное изучение;
- всё показываем через `dotnet` CLI;
- каждая лаба добавляет к сервису ровно один слой из прочитанной лекции.

## Добавлено сверх заметок

Без этого сервис не собрать:

- асинхронность как половина отдельной лекции (Л6);
- обработка ошибок и исключения как тема языка (Л4) и как единственное middleware (Л8);
- работа с файлами как наглядный пример владения unmanaged-ресурсом (Л6);
- делегаты, лямбды и замыкания как основание LINQ (Л4);
- исходящие HTTP-вызовы: фабрика, типизированные клиенты, устойчивость (Л10);
- контейнер как единица поставки (Л2) и конфигурация через переменные среды (Л10);
- OpenAPI и версионирование API (Л9).

Сознательно **не** входит в курс: ProblemDetails и прочие надстройки над ответом — фокус
на чистом WebAPI, ошибки формирует exception handling middleware.
