# Лекции курса «.NET: от установки до веб-сервиса»

Пятнадцать устных сценариев по 80 минут. Каждая лекция лежит в своём подкаталоге.
Источник структуры и тезисов: [../course-structure.md](../course-structure.md) и [../lecture-notes.md](../lecture-notes.md).

## Пометки в тексте

- `[СЛАЙД: …]` — что должно быть на слайде в этом месте; спикер не делает лайв-кодинг, весь код и вывод показываются слайдами.
- `[ВОПРОС В ЗАЛ]` — спикер ждёт реакции зала.
- `[ПАУЗА]` — дать залу подумать.
- `[ЛАБА N — подробности для составителя: …]` — задание, обязательные проверки, типичные ошибки и дополнительное задание для лабораторной.
